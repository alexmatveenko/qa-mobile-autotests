# Дефекты и расхождения с ТЗ (Alfa-Test)

Источник ТЗ и исходников приложения: [lunin-vadim/qa-mobile](https://github.com/lunin-vadim/qa-mobile) — файл «Требования работы приложения.docx».  
Учётные данные: `Login` / `Password`.

**Подход:** автотесты (5 сценариев) проверяют только формулировки, которые **однозначно** есть в ТЗ; см. `ui/authorization/`, `utils/Requirements.java`. Для прогона в репозитории лежит **`app/alfatest.apk`** (сборка с исправлением **DEFECT-1**, без изменения бизнес-логики).

Нумерация **DEFECT-1 … DEFECT-6** — только пункты из таблиц ниже, без пропусков.

## DEFECT-1 — сборка (исправлено в APK)

| ID | Суть | Статус |
| --- | --- | --- |
| DEFECT-1 | **BUILD-1:** в upstream не собирается из‑за опечатки в `app/src/main/java/com/alfabank/qapp/domain/LoginUseCase.kt`: `LoginResult.Error()-` → `LoginResult.Error()` | Исправлено **только** в `app/alfatest.apk` |
